# Quasar Design System workspace

pnpm workspace for the design system.

| Path | Content |
|---|---|
| `packages/quasar` | the published Quasar package ([README](packages/quasar/README.md)) |
| `apps/gallery` | Quasar gallery and Playwright visual gate (private) |
| `apps/storybook` | Storybook catalog (private) |
| `examples/shadcn-reference` | pinned upstream shadcn-vue reference (private) |

```bash
pnpm install
pnpm build
pnpm gallery:test
```
